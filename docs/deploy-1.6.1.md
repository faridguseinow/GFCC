# Исправление GFCC Oasis 1.6.1

1. Убедиться, что в базе `cl449121_gfcc` выполнен `002_create_app_visit_daily.sql`.
2. Распаковать `gfcc-oasis-web-1.6.1.zip` прямо в `/www/gfcc-oasis.ru/` с заменой файлов.
3. Проверить `https://gfcc-oasis.ru/api/app-visits.php`: GET должен вернуть JSON с `METHOD_NOT_ALLOWED`, а не HTML 404.
4. Открыть приложение версии 1.6.1, затем обновить админку. Первый визит должен появиться не позднее чем через 10 секунд.
5. Открыть карточку «Подключённые клиенты» и убедиться, что список отображается на iPhone.

Исправления версии:

- endpoint посещений перенесён в основной Web-архив;
- устранён 404 на `api.gfcc-oasis.ru/app-visits/`;
- запрос списка клиентов использует полный HTTPS URL;
- добавлен совместимый с Safari разбор даты MySQL;
- упрощена страница «О приложении».
